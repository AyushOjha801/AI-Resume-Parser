# AI Resume Parser & Candidate Matcher

An AI-powered resume screening tool built with Python, Groq, and Pydantic to help recruiters identify candidates whose profiles best align with a job description.

## Problem Statement

Recruiters often receive a large number of resumes for a single job opening. Manually reviewing each resume against the job description takes considerable time and effort. Identifying relevant skills, evaluating experience, and shortlisting suitable candidates can become repetitive and time-consuming.

I built this project to simplify that initial screening process by using AI to extract candidate information, understand job requirements, and generate resume-to-job matching scores.

## What It Does

- **Job Description Analysis:** Extracts important requirements, skills, qualifications, and responsibilities from a job description.
- **Resume Parsing:** Reads resumes in PDF and DOCX formats and extracts candidate details, skills, experience, education, projects, and certifications.
- **Structured Data Extraction:** Converts unstructured job descriptions and resumes into structured JSON using Pydantic schemas.
- **Candidate Matching:** Compares candidate profiles against job requirements using an LLM.
- **Match Scoring:** Generates a match percentage along with matching skills, missing skills, experience assessment, and a short verdict.
- **Candidate Ranking:** Sorts candidates based on their generated match scores and displays the top and lowest two candidates.

## How It Works

1. A job description is provided to the system.
2. Groq LLM analyzes the job description and extracts structured requirements.
3. The application reads resumes from a local folder.
4. Each resume is parsed into structured candidate information.
5. The candidate profile is compared against the extracted job requirements.
6. An AI-generated match score and evaluation details are produced.
7. Candidates are ranked based on their scores.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AyushOjha801/AI-Resume-Parser.git
cd AI-Resume-Parser
```

### 2. Install dependencies

Install [uv](https://docs.astral.sh/uv/) if you don't already have it.

```bash
uv sync
```

### 3. Configure your Groq API key

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key
```

Get your API key from [Groq Console](https://console.groq.com/).

### 4. Add resumes

Create a folder named `resumes` in the project root and add candidate resumes in PDF or DOCX format.

### 5. Run the application

```bash
uv run python resumeparser.py
```

## Output

The application displays:

- Candidate name
- Resume-to-job match score
- Matching skills
- Missing important skills
- Experience requirement assessment
- Final AI-generated verdict
- Top 2 and lowest 2 candidates

## Current Limitations

- The job description is currently defined directly in the Python script.
- Resume extraction supports PDF and DOCX files.
- Image-based PDFs requiring OCR are not supported.
- Candidate evaluations and match scores are generated by an LLM and may not always be accurate.
- The application is currently a command-line tool.

## Future Improvements

## Disclaimer

This project is intended to assist recruiters with initial resume screening. AI-generated scores should not be treated as definitive hiring decisions. Candidate evaluation should always involve human review.
